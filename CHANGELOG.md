# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-09-26

### Added
- Initial release of NFT licensing package
- Standard non-commercial license terms
- Commercial license terms
- JavaScript API for license generation
- Markdown templates for both license types
- Attribution requirements
- Copyright protection for JohnWayne (B. John Werler) assets

### Features
- `getStandardLicense()` - Get non-commercial license terms
- `getCommercialLicense()` - Get commercial license terms  
- `generateLicenseText()` - Generate formatted license text
- Template files for easy reference
- Comprehensive README with usage examples
